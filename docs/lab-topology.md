# 실습 구성 관계

[저장소 소개](../README.md)

## 노트에 기록된 순서

| 단계 | 구성 요소 | 노트의 작업 | 다음 단계에서 필요한 이유 |
|---|---|---|---|
| 1 | `esxi00`·`esxi01`·`esxi02` | ESXi VM과 호스트 설치·설정 | VM을 실행할 호스트 확보 |
| 2 | vCenter VM | 관리 서버 설치, ESXi 호스트 추가 | 호스트와 클러스터의 중앙 관리 |
| 3 | NAS | iSCSI 생성, LUN 매핑·제공 | 호스트가 사용할 공유 스토리지 준비 |
| 4 | `BasicCluster` | 노트의 호스트 목록 중 두 호스트 묶기 | 클러스터 기능의 적용 대상 지정 |

노트는 호스트 설치 대상을 세 대로, `BasicCluster`의 구성원을 두 호스트로 기록합니다. 각 호스트 이름과 클러스터 구성원 주소의 대응은 명시하지 않아 여기서 확정하지 않습니다. 노트에는 iSCSI의 상세 initiator, target, 인증 및 실제 LUN 연결 결과가 없습니다.

## 관리와 데이터 경로

- **Host Client**는 개별 ESXi 호스트를, **vSphere Client**는 vCenter에 등록된 호스트·클러스터를 관리하는 접점으로 기록되어 있습니다.
- **표준 vSwitch**와 VM port group은 VM 네트워크 연결에, VMkernel port group은 호스트 서비스 트래픽 설정에 쓰입니다. 노트에는 NIC 추가와 teaming 구성 항목도 있습니다.
- **Datastore**는 VM 파일을 담는 저장소입니다. 노트에는 생성·마운트/해제·용량 증가가 항목으로 적혀 있으나 각 변경의 성공 증거는 남아 있지 않습니다.

관리 인터페이스, iSCSI, VM 네트워크의 분리 방식과 VLAN 값은 기록으로 확인되지 않습니다. 따라서 여기서 임의의 네트워크 설계나 현재 접근 가능한 엔드포인트를 제시하지 않습니다.
