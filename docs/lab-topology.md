# vSphere 구성 관계

[저장소 소개](../README.md)

다음은 ESXi 호스트 3대 가운데 2대를 vCenter 클러스터에 포함하는 **논리 시나리오**입니다. 특정 호스트 이름·주소·인증 정보는 전제하지 않습니다.

| 순서 | 구성 요소 | 역할 | 확인할 관계 |
|---|---|---|---|
| 1 | ESXi 호스트 | VM을 실행하는 하이퍼바이저 | 관리 주소와 물리 NIC, 호스트별 네트워크 |
| 2 | vCenter | 호스트·클러스터의 중앙 관리 | 호스트 등록 상태와 클러스터 구성원 |
| 3 | NAS·iSCSI LUN | 여러 호스트가 접근할 공유 스토리지 | initiator·target·인증·경로·datastore 표시 |
| 4 | 클러스터 | 두 호스트의 관리 단위 | 대상 호스트, 네트워크와 스토리지 전제 |

## 관리와 데이터 경로

- **Host Client**는 단일 ESXi 호스트를, **vSphere Client**는 vCenter에 등록된 호스트와 클러스터를 관리합니다.
- **표준 vSwitch**와 VM port group은 VM 네트워크 연결에, VMkernel port group은 호스트 서비스 트래픽에 사용됩니다. 서비스별 VMkernel 설정과 실제 물리 uplink를 대조합니다.
- **Datastore**에는 VM 파일이 저장됩니다. iSCSI LUN이 모든 대상 호스트에서 기대한 상태로 표시되는지 확인합니다.

관리, iSCSI, VM 트래픽의 실제 분리 방식이나 VLAN은 이 문서만으로 정할 수 없습니다. 네트워크와 스토리지 설계는 대상 호스트·스위치·NAS의 설정을 확인한 뒤 결정합니다.
